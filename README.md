# E-Commerce Website

A full-stack MERN e-commerce platform that provides a complete online shopping experience with secure authentication, product browsing, shopping cart management, payment integration, order tracking, reviews, and an administrative dashboard for inventory and order management.

---

# 🚀 Features

* JWT-based Authentication & Authorization
* User Registration & Login
* Product Catalog
* Product Categories
* Search & Filters
* Shopping Cart
* Wishlist Support
* Secure Checkout
* Razorpay/Stripe Payment Integration
* Order Management
* Order Tracking
* Product Reviews & Ratings
* Inventory Management
* Admin Dashboard
* Responsive UI

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/ecommerce-website.git
```

Install backend dependencies

```bash
cd server
npm install
```

Create a `.env` file

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key

RAZORPAY_KEY_ID=your_key
RAZORPAY_KEY_SECRET=your_secret
```

Install frontend dependencies

```bash
cd client
npm install
npm run dev
```
